# Sports-betting GitHub study

Preparation repo for a Tensorsoft source-level review of the sports-betting and prediction-market open-source ecosystem on GitHub — published at [TensorSoftTech/sport-betting-data](https://github.com/TensorSoftTech/sport-betting-data).

**Census:** 8,021 repositories found → 3,462 cloned → 2,782 deep-read at source level (wave 1: 1,007 venue/high-signal + wave 2: 1,775 remainder), with live HTTP probes of load-bearing data claims (November 8, 2026).

## Where it publishes

The study ships on the Tensorsoft research page — not in this repository’s working drafts.

- Site: [tensorsoft.tech](https://tensorsoft.tech)
- Research: [tensorsoft.tech/research](https://tensorsoft.tech/research)
- Related field notes: [Polymarket open-source tools](https://tensorsoft.tech/research/polymarket-open-source-tools) · [Open-source trading tools](https://tensorsoft.tech/research/open-source-trading-tools)

## Layout

- `data/` — census, deep-read verdicts (`deepreads-meta.jsonl` full corpus + `deepreads-1007.json` priority wave), screen-vs-read agreement, venue-lag series/chart, and probe ledgers
- `study/` — local drafts (`post1`–`post3`), final journal (`merged.md`), and the venue-lag chart (gitignored; the finished piece publishes on the research page)
